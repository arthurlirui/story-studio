# 《黑玫瑰归来》完整大纲（8章 + 人物弧光 + 写作检查清单）

## 逐章

### 第1章《海底》(3000-4000字)
- 开篇500字钩子：站在游艇甲板上，丈夫从背后拥抱，下一秒推入漆黑的海
- 闪回：Rossi家族独女嫁Moretti首领，自由恋爱非联姻
- 三个月前Colombo家族儿子在Moretti地盘被杀，议会要凶手
- Vincenzo将Serena推出去背锅，Marco伪造证据
- 章尾：海水中停止挣扎→一只手拽出水面，老人问"你想活吗？"
- 钩子：谁救了她？敌是友？
- 情绪：背叛、死亡恐惧、绝望、重生种子

### 第2章《黑玫瑰》(3000-4000字)
- 五年后"黑玫瑰"传说：性别长相不明，两年整合中小家族，用信息控制一切
- 闪回：Colombo老教父Don Roberto救人，给出选择：走人or学本事复仇
- 五年训练蒙太奇
- 现在：瓦解了Moretti三条走私路线
- 章尾：助手报告Vincenzo本人要求面对面谈判
- 钩子：她见还是不见？
- 情绪：权力感、隐忍复仇、掌控欲

### 第3章《谈判桌》(3000-4500字)
- 废弃剧院包厢谈判，灯光设计让她先看到他
- Vincenzo带Marco到达，老了但气场仍在
- Serena走出阴影→Vincenzo表情：冷漠→困惑→震惊
- 五秒才说出"...Serena?"
- 她平静："叫我黑玫瑰。走私路线的事，三百万。"
- 他签了，临走想解释→她："下次预约。每周二下午3-3:30。"
- 章尾：手指微抖，Lucia问后悔没杀他？→"我要让他活着看我拿走一切"
- 钩子：他接下来怎么做？
- 情绪：马甲打脸巅峰、复仇快感、掌控中暗藏脆弱

### 第4章《棋盘之上》(3000-4000字)
- Vincenzo砸办公室，质问Marco"你不是说她死了！"
- 五族议会紧急会议：黑玫瑰申请席位（控制>=3条路线即可）
- Serena议会首秀：关税协议砍到8%，冷静精准
- Vincenzo投票赞成她的席位
- 章尾：Lorenzo Colombo走廊里说"他看你的眼神不是敌人，是以为死了的爱人"
- 钩子：是愧疚还是爱情？Serena怎利用？
- 情绪：权力攀升、智慧感、暧昧张力

### 第5章《裂痕》(3500-4500字)
- Vincenzo追查真相：镜像指纹、时间戳被改
- 质问Marco→"是你父亲老Moretti的命令"
- 真相：老Moretti不让儿子有弱点，Serena是完美替罪羊
- Vincenzo差点杀Marco，最后停手
- 他发消息给Serena："我知道真相了。不是我做的。——V"
- 章尾：Serena看了消息沉默→"不管真假，改变不了他看着我下沉"
- 钩子：他会怎么做？她会给他机会？
- 情绪：真相揭露、悔恨、信任崩塌、恨与爱的裂痕

### 第6章《火线》(3500-4500字)
- Bonanno+Gambino弹劾Serena席位
- Bonanno雇杀手在隧道伏击
- 枪战危急→三辆黑SUV冲进来，是Moretti的人，Vincenzo亲自带队
- 战后："你受伤了"/"看得出来"/"不管你怎么想，我欠你一条命"
- 章尾：浴室处理伤口，镜子里——最难的不是原谅背叛，是面对还在乎的人
- 钩子：暗杀谁策划？内心防线崩塌
- 情绪：生死危机、极限救援、内心松动、暧昧巅峰

### 第7章《新教父》(4000-5000字)
- Serena挖出Bonanno军火走私+平民伤亡证据
- 议会巅峰对决：公开证据，Bonanno逐出
- Vincenzo站起："Moretti提议黑玫瑰接任Bonanno席位"
- 全场震惊→"我不要施舍"/"这是认错"
- 投票通过，黑玫瑰成合法Mafia权力
- 章尾：深夜，七年前婚礼教堂，她坐台阶上，他下车靠着车门看她——隔着一条街和五年
- 钩子：还可能吗？
- 情绪：权力巅峰、公开认错、心碎与希望并存

### 第8章《彼岸》(3000-4000字)
- 三个月后，五族变六族，清除残余势力
- Don Roberto去世："很高兴你没杀他。恨容易。在还在乎的人面前保持骄傲——更难。"
- 葬礼后：Vincenzo提议喝咖啡→"我不喝咖啡了。茶。"
- 咖啡馆全对话真相：Marco制造遗书骗他说Serena跳海，他信了
- Serena："你父亲是恶人，但他有一个好儿子。"
- 结尾：没原谅但留希望——"也许五年不够，也许十年。但如果你等——"
- "我等。已经学了五年后悔，不介意再学十年。"
- 最终：走出咖啡馆，雪落下，步伐——慢了一点点
- 续集彩蛋：欧洲古老血族家族关注崛起，派人来了
- 情绪：和解、告别、等待、希望、世界观扩展
