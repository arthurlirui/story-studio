## 狼人题材（4个）

### 01《银月囚徒》
题材：狼人 + 追妻火葬场。她化身狼形救了Alpha一命，他以为是贵族女狼，在全族悬赏找了她三年——却不知救命恩人是被他亲自赶出狼群的残疾女仆。双重信息差：男主全族悬赏时女主在后厨刷盘子——她因那场救援动用禁术失去变身能力。三年后重逢，他的内在狼比她先认出她。✅短剧适配

### 02《血月替罪》
题材：狼人 + 替嫁闪婚 + 真假千金。姐姐毒杀狼王联姻对象嫁祸给她，她被绑上花轿送进狼域。狼王冷笑："我最讨厌骗子。"真正的骗子坐在观众席等她的尸体。女主背负杀人罪新婚夜被判死刑，须在7天自证清白——真凶是每次来送"温暖"的姐姐。✅悬疑+复仇双引擎

### 03《狼群的女王》
题材：狼人 + 逆袭爽文 + 马甲打脸。她作为"没有狼形的废物"被未婚夫当众退婚。三个月后，七位Alpha从各大洲赶来——求她收下狼族失传千年的月光王座。"没有狼形"是因为内在狼是远古种太大被误认为不存在。退婚宴上内在狼挣脱封印，全场狼人跪地。✅打脸密度极高

### 04《契约狼后》
题材：狼人 + 先婚后爱 + 倒计时追妻。她嫁给据说"疯掉"的前Alpha。他只在月圆之夜恢复清醒——每月只有那天是丈夫，其余29天是一头不认识她的野兽。30天内通过月圆之夜的丈夫收集线索找出他被陷害疯掉的真相，第30天他清醒超24小时。✅倒计时结构天然适配

## 吸血鬼题材（4个）

### 05《血奴的反击》
题材：吸血鬼 + 追妻火葬场 + 觉醒重生。她的血能让吸血鬼白日行走，被囚为活体血库十年。她死那天他没来。重生后第一件事——把血卖给他最大的敌人。不是"逃开"而是"站在敌人那边让他看着"，每个拒绝瞬间都是爽点。✅重生复仇经典公式

### 06《初拥》
题材：吸血鬼 + 强制绑定 + 先婚后爱。她以为自己是血族"食物"——直到初拥仪式上创造她的公爵跪在她面前："你是我转化的人，我要对你余生负责。包括你的爱。"她以人类身份嫁给公爵为救弟弟，但若她不转化公爵心跳会30天内停止。初拥不是权力是双向责任。✅双向救赎

### 07《亲王的赎罪》
题材：吸血鬼 + 倒计时追妻 + 马甲。活了800年的亲王收到邮件——他血契伴侣还活着。五百年前他看着她被烧死。而她却伪装成了专门猎杀吸血鬼的猎人。她假死500年建立反血族组织，等自己够强杀他——却不知当年火刑是第三方设计的陷阱。✅800年时空纵深

### 08《血月双生》
题材：吸血鬼 + 真假千金 + 替嫁闪婚。双胞胎姐妹：一个被血族亲王选为新娘，一个是私生女。姐姐婚礼前自杀，妹妹被塞进婚纱——亲王掀开头纱："我知道你不是她。我选的一直是你。"亲王需要私生女的罕见抗诅咒基因。她发现真相后用他最想要的东西——她的血——换自由。✅双胞胎视觉冲击

## Mafia/帮派题材（4个）

### 09《黑玫瑰归来》
题材：Mafia + 追妻火葬场 + 马甲打脸。被Mafia首领丈夫亲手推下海。五年后地下世界都在讨论代号"黑玫瑰"的新教父——她推开会议室门在丈夫震惊目光中坐上主位。五年前她被丈夫推出去背灭门的黑锅，五年后以新教父身份归来，他要谈判却不知对面是他亲手杀死的妻子。✅权力反转

### 10《血色联姻》
题材：Mafia + 替嫁闪婚 + 先婚后爱。两大Mafia家族停战联姻。姐姐不愿嫁"杀人不眨眼的恶魔"，她替姐姐踏进敌人家族庄园。后来发现那个"恶魔"每晚去教堂为十年前误杀的小女孩祈祷——那个小女孩，是她。双线叙事：联姻博弈+十年前误杀真相。他不是恶魔只是被推到前线承担罪责的长子。✅教堂场景冲击

### 11《前妻的复仇》
题材：Mafia + 带球跑 + 追妻火葬场。怀胎五月被赶出庄园——丈夫要娶能带来军火渠道的女人。七年后她被请回——女儿是唯一能和儿子骨髓配型的人。不是传统后悔——女儿的病让决裂者被迫重聚。她为救女儿回来，他不给骨髓——他要她重新回到身边。✅医疗悬念+带球跑

### 12《地下女王》
题材：Mafia + 马甲打脸 + 逆袭。Mafia家族最不起眼的小女儿——不会开枪不会谈判被当联姻筹码。直到家族遭灭顶之灾，她用了三分钟让敌人家族一夜之间从地下世界消失。"废物小女儿"才是真正继承人——父亲临终把地下网络控制权交给她，因为她"不会开枪但会让人开枪"。✅智商压制型打脸

## 西幻魔法题材（4个）

### 13《假面女巫》
题材：魔法学院 + 马甲打脸 + 逆袭。隐藏实力的最强女巫在魔法学院被当成废物。清理深渊裂隙的实战考核里全班覆没——她放下扫帚一个人走进裂隙。全校看不起的清洁工女巫→独自清理SSS级裂隙。院长颤抖着问"谁教的"，她说"自学"。✅魔法视觉冲击

### 14《三十日王妃》
题材：魔法王国 + 倒计时追妻 + 先婚后爱。王子需30天内娶妻保王位，选中平民女孩。她只给他30天——"你会爱上我"他说，"30天后我走"她说。第29天她消失，第30天他退位追她。她把30天当契约，他把30天当追求。她失踪不是因为不爱——是魔法血脉觉醒必须回学院镇守深渊。✅双向奔赴

### 15《灵魂契约》
题材：西幻魔法 + 先婚后爱 + 追妻火葬场。为救家族女猎魔人与暗黑大法师缔结灵魂契约结婚。所有人都说他吞噬灵魂——但月圆之夜他在她面前露出被诅咒囚禁了三百年的真实面容。外人眼里他是邪恶之源，实际上他是三百年前独自镇压深渊裂缝把自己也封印其中的最后一位圣法师。✅反转+救赎

### 16《魔法学徒》
题材：魔法学院 + 重生换嫁 + 逆袭。重生回到被魔法学院开除的前一天。前世她为男友放弃入学名额，换来的是一句"你这种没天赋的人别拖我后腿"。这一世她把录取通知摔在男友脸上——后来男友来到学院求她指点时，她是学院史上最年轻的副院长。✅大女主独立

## 西方王室/贵族题材（4个）

### 17《王冠之下》
题材：欧洲王室 + 真假千金 + 追妻火葬场。她是王室流落在外的长公主，被找回来当天就被安排嫁给邻国王子当政治筹码。王子在婚礼上说"你不是我要的那个人"。一年后她揭开了王室内部叛国的阴谋——王子跪在她面前："你不是我要的那个人，你是这个王国需要的人。"✅王室权谋

### 18《替身王妃》
题材：西方王国 + 替嫁闪婚 + 倒计时追妻。为救被囚禁的姐姐她替嫁国王。国王发现替身后给了她30天——"让我爱上你，或者死。"但她不知道他也在倒计时——30天后刺客联盟会来取他的命。第29天她为他挡了一剑，第30天她拿下刺客联盟头目的面具——那是她失踪了十年的父亲。✅王室+家族谜团

### 19《玫瑰战争》
题材：欧洲贵族 + 重生换嫁 + 追妻火葬场。被丈夫和妹妹联手毒死。重生到出嫁前——这一次她选了丈夫的冷面兄长、那个据说在战场上杀过一千人的公爵。新婚夜公爵对她说："我不是什么好人。但我从不背叛自己选择的人。"后来前夫跪在她面前求她回来时，公爵只说了四个字："她是我的。"✅重生+选择权

### 20《女王棋局》
题材：欧洲王室 + 先婚后爱 + 马甲打脸。她是被全欧洲嘲笑的书呆子公主，嫁给邻国"战无不胜"的国王。新婚第一天她走进他的作战会议室，花了十分钟推翻了让他打了三年的战争方案。"谁教你的？""一本兵书。""你还会什么？""任何你想不到的事。"✅智商压制+反差萌
